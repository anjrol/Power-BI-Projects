# Superstore Sales Dashboard (Power BI)

## 📊 Overview
This project uses the Kaggle Superstore dataset to create an interactive Power BI dashboard.  
The dashboard provides insights into sales, profit, shipping modes, and customer segments.

## 📂 Dataset
- Source: Kaggle – Superstore Sales Data
- Records: ~10,000 transactions
- Columns include: Order ID, Order Date, Ship Date, Ship Mode, Customer Name, Segment, Country, City, State, Region, Product Category, Sub-Category, Sales, Quantity, Discount, Profit.

## 🛠️ Steps Taken
1. Imported dataset into Power BI.
2. Cleaned and transformed data using Power Query (date formatting, calculated fields).
3. Created calculated measures:
   - Total Sales
   - Total Profit
   - Average Discount
   - Profit Margin
4. Built visuals:
   - Bar chart: Sales by Region
   - Line chart: Monthly Sales Trend
   - Pie chart: Sales by Category
   - Map: Sales by State
   - KPI cards: Total Sales, Profit, Orders
5. Added slicers for Year, Region, and Category for interactivity.

## ✨ Key Insights
- The West region generated the highest revenue.
- Technology category contributed the largest share of profit.
- Standard Class shipping mode was most frequently used.
- December showed peak sales activity.
